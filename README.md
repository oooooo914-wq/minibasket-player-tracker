# MiniBasket Player Tracker

スマートフォンの試合動画から、指定したミニバス選手を端末内で追跡し、最終的に走行距離・出場時間・軌跡・ヒートマップを算出するPWAです。

## MVP 0.1

- スマートフォン内の動画を選択
- 動画はサーバーへアップロードせずブラウザ内で処理
- MediaPipe Object Detectorで人物を検出
- 検出された選手をタップして追跡対象を指定
- 対象に近い人物候補を継続追跡
- マーカーと簡易軌跡を動画上に表示
- PWAとしてホーム画面から起動可能

## プライバシー

動画ファイルは端末内で読み込み、解析のために本アプリのサーバーへ送信しません。AIモデル等のアプリ資材はネットワークから読み込みます。
